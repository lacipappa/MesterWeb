Antes de empezar

¿Necesito Excel?

No. MesterSaldo es un programa independiente para Windows. Puedes consultar sus tablas y gráficos, y exportar informes a PDF sin Excel.

¿Puedo trabajar con varios años?

Sí. Puedes seleccionar año y mes, revisar los registros y comparar periodos sin crear un archivo nuevo para cada año.

¿En qué idiomas está disponible?

La interfaz está disponible en español, inglés y húngaro. Puedes cambiar el idioma dentro del programa.

¿Importa automáticamente movimientos del banco?

No. Los movimientos se registran en el programa. Las suscripciones y las cuotas de deudas pueden vincularse con transacciones existentes mediante confirmación, para evitar duplicar gastos.

¿Cuándo podré descargarlo y cuánto costará?

El instalador para Windows está en preparación. El precio y las condiciones de licencia se comunicarán cuando estén confirmados. Puedes escribirnos para solicitar información.

¿Los avisos funcionan con el programa cerrado?

Los próximos eventos y vencimientos se muestran dentro de MesterSaldo cuando el programa está abierto.
